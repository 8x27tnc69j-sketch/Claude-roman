# Metal Shelving (этажерка) — кастомный чертёж

Параметрический проект кастомной металлической этажерки для хранения принадлежностей для творчества. Рама — сварная из профильной трубы, полки — из листа стали или фанеры.

## Что уже есть в этой папке

```
metal-shelving/
├── README.md              ← этот файл
├── SETUP.md               ← установка FreeCAD + MCP на твоей машине
├── requirements.txt       ← Python-зависимости (build123d, ezdxf)
├── venv/                  ← Python-окружение (локальное, в git не входит)
├── scripts/
│   └── etazherka.py       ← параметрический генератор этажерки
├── output/                ← сюда падают STEP / DXF / cut_list.md
│   ├── etazherka.step     ← 3D-модель (открыть в FreeCAD или онлайн-вьюере)
│   └── cut_list.md        ← карта раскроя + ведомость материалов + заметки по сварке
├── welding-symbols/       ← библиотека символов сварных швов (ISO/AWS, DXF)
└── docs/
```

## Быстрый старт (2 минуты)

```bash
cd metal-shelving
./venv/bin/python scripts/etazherka.py
```

Результат — 3D-модель `output/etazherka.step` и `output/cut_list.md` с карту раскроя.

## Как подставить свои параметры

Открой `scripts/etazherka.py`, найди блок `class Params:` в начале файла. Правь значения (все в миллиметрах), сохраняй, запускай заново.

По умолчанию:
- Ш × Г × В = 600 × 400 × 1500 мм
- 4 полки
- Рама: профильная труба 25 × 25 × 2 мм
- Полки: лист стали 3 мм
- Сзади диагональная растяжка (укос) для жёсткости

## Что дальше

1. Открой `.step` файл в FreeCAD — посмотри на модель глазами.
2. Если что-то не нравится (пропорции, число полок, высота) — правь `Params`, перезапускай.
3. Когда модель устраивает — читай `output/cut_list.md` и иди с ним в металлобазу.
4. Для рабочего чертежа с размерами и сварными швами — см. `SETUP.md`, раздел про FreeCAD TechDraw.

## Минимальный набор инструментов для сварки

- Углошлифовальная машина (болгарка) ⌀125 + отрезные диски 1 мм
- Полуавтомат MIG или инвертор MMA (для 25×25×2 хватит 140-160 А)
- Струбцины, угольник, магнитные держатели 90°
- Ровная стальная плита или чугунный стол для сборки
- Средства защиты: маска хамелеон DIN 9-11, краги, респиратор при зачистке

Точные токи и электроды — в `output/cut_list.md` после запуска скрипта.

## Если нужен полный workflow с AI-контролем FreeCAD

См. `SETUP.md` — там расписана установка MCP-сервера `contextform/freecad-mcp`, после чего Claude сможет прямо из чата строить модель в твоём FreeCAD, генерировать чертежи TechDraw и подставлять сварные символы.
